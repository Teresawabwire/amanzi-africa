# Amanzi Africa website

A responsive, static company website for Amanzi Africa Agritech Limited, designed for GitHub Pages.

## Brand direction
- Deep forest green: `#003820`
- Leaf green: `#106840`
- Fresh green: `#189040`
- Pale sage: `#98C8A8`
- Light green-grey: `#EAF1EC`
- Antique gold: `#B8860B`
- White: `#FFFFFF`

The logo is cropped directly from the final end-card of the supplied 15-second Amanzi Africa marketing video. It preserves the exact three-leaf mark, AMANZI AFRICA wordmark, colours and white rectangular lock-up shown in the video. The hero image is a still from the supplied 15-second marketing film. The original film and SME services e-brochure are included in `assets/`.

## Publish with GitHub Pages
1. Create a GitHub repository named `amanzi-africa` (or `YOUR-USERNAME.github.io` if you want it to be the account's main site).
2. Upload the contents of this folder to the repository root. Do not upload the enclosing ZIP file as the site.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will provide the public Pages URL after deployment.

## Before public launch
- Confirm that the telephone numbers, email and postal address are current.
- Confirm that the selected marketing-film still is approved for public website use.
- Add a custom domain later if desired.
- Consider adding a privacy notice and enquiry form only after deciding how enquiries and personal data will be handled.

## Imagery direction
All people shown in the website's image gallery are depicted as African farmers or agribusiness participants, across primary production, aggregation, fresh-produce trading and food processing. These are illustrative AI-generated images, not photographs of actual Amanzi Africa clients or partners.
